# LLM 用量 · 试用版 0.2.1

Windows 托盘工具，使用 AMD LLM Gateway 的只读 `GET https://llm-api.amd.com/api/UsageStats` 接口查询当前密钥的用量。无需浏览器或网页 Okta 会话。

## 使用

双击 `build/LlmUsageTray.exe`。第一次使用在设置中填写 API key 和 `user` 请求头。`user` 默认值为 `ntid`，使用时替换为自己的 NTID；源码没有内置个人密钥或真实用户名。

- 仅显示托盘图标，不显示桌面悬浮条。图标形似电池，亮色填充表示剩余预算：花费 $700、预算 $1,000 时填充约 30%。花费增加后亮色条向左缩短，详情进度条采用相同逻辑。
- 剩余高于 20% 为绿色，大于 0% 且不超过 20% 为黄色，耗尽或负数为红色。超预算时为空电池红色轮廓和减号；剩余金额和比例保留负数，不显示成满电池。
- 悬停显示今日估算费用、本月估算费用、月度预算和剩余比例。点击打开详情，Esc、关闭窗口或「收起」隐藏详情，继续后台刷新。极大金额在悬停提示中自动缩写，详情保留完整数字。
- 详情包含今日与本月的费用、token、请求数、平均每次请求消耗，以及各模型的输入/输出/总 token 和费用占比。右上方可切换今日或本月的模型明细。
- 默认每 5 分钟自动刷新，可在设置中改成 1–60 分钟；支持手动刷新。失败后自动退避重试，保留上次数据并显示旧数据状态。
- 日期固定按北京时间 UTC+8。今日从北京时间 00:00 起，本月从月初北京时间 00:00 起，查询参数转换成 UTC。跨日后不会把昨日值当作今日，跨月后不会把上月值当作本月。
- 托盘右键可刷新、打开设置和退出。Windows 若将图标收入隐藏区域，可通过任务栏“▴”展开。断网时保留旧占比，图标变灰并加黄色点；没有本月数据时显示问号。
- 试用版没有设置开机启动。

## 月度预算

默认 $1,000，在设置中修改“月度预算 USD”，支持小数且必须大于零。保存后立即重算占比，不清空已有用量。

2026-11-16 检查官方 OpenAPI 文档未发现预算接口或相关字段；实测 `/api/Home/AppInfo`、`/api/Home/AppSetting` 返回版本/配置资料，没有个人月度预算。`UsageStats` 本身也没有预算字段。

本版使用用户自行设置的参考预算，不是公司官方预算。TokenOps 显示 $1,300 时可以手动设置为 1300；预算变更需要自行更新。程序不阻止超预算调用。

## 数据口径

金额使用 `approxChargeInUSD`，属于接口估算费用，已观察到它与 TokenOps 网页账单金额不同。预算占比和剩余金额也按估算值计算，不代表公司正式剩余额度。

总 token 按接口原值展示，不以输入和输出之和代替，也不推算缓存命中率。网关分类展示在模型名称的悬停提示中，不把分类名解释成实际模型供应商。

统计对应接口返回的应用/密钥范围，尚未证实是否覆盖个人网页所有工具和密钥。最后成功更新时间是本机收到响应的时间；接口未返回底层统计数据的更新水位。

404 只有正文明确为 `Not found any usage of application on given date range.` 时才作为空用量；其他 404、认证错误、非 JSON 或字段变化均显示失败并保留旧数据。

## 本机存储

默认在 `%LOCALAPPDATA%\LlmUsageTray`：

- `secret.dpapi`：Windows DPAPI 当前用户加密的 API key；二进制和源码不含真实密钥。
- `config.json`：user 请求头、刷新间隔、月度参考预算。
- `cache.json` / `.bak`：最后成功查询的整理后统计，包含应用名称，不包含原始密钥或对话内容。

从 0.1.0 升级保留密钥和统计缓存，预算补为 $1,000，旧小条位置不再使用。换 key 或 user 后不会复用旧账号缓存。密钥只发送到固定 HTTPS 网关地址，禁止自动跟随重定向。无额外遥测或第三方数据上传。

## 构建与验证

需要 Windows x64、.NET Framework 4.8。使用系统 C# 编译器，不需要 Visual Studio、NuGet 或额外运行时下载。

```powershell
.\scripts\build.ps1 -Test
.\scripts\package.ps1
```

输出为 `build/LlmUsageTray.exe` 和相邻 `.config`。复制程序时保留两者；便携包为 `dist/LlmUsageTray-0.2.1.zip`。源码兼容 C# 5。

开发参数：`--show-details` 启动后展开；`--data-dir <目录>` 隔离配置；`--self-test` 自检；`--render-icons` 生成图标状态预览；`--configure-stdin` 从标准输入两行读取 key、user，完成 DPAPI 配置后退出。

## 目前限制

46 项自检覆盖通用用户名默认值、日期、响应解析、负预算、旧配置迁移、提示长度、实际图标填充及颜色、密钥加密和缓存恢复。图标与详情进度条统一显示剩余预算。真实长时间待机、网络切换、多显示器混合 DPI 仍需使用验证。没有历史趋势持久化、官方预算、按软件/会话拆分或缓存 token 明细。
